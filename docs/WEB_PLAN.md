## 控制边界

URL 只来自本地配置中预先授权的 `subscriptions` 来源档案；管理订阅引用这些档案，不能提交任意 URL。现有配置订阅首次仍自动启用以兼容 daemon；新增订阅可引用同一档案，有独立 ID。停用取消未来抓取，不取消已有下载/做种/导入，不删除任何文件。编辑来源只允许尚未产生资源的订阅，避免改变已绑定的来源语义。

HTTP 写操作串行进入领域引擎，使用 job version 防过期操作；确认仍要求 plan version + digest。重试只清除退避，不重置下载/计划或归档状态。规则修改只追加新版本，已开始的计划不重算。长操作客户端显示忙碌，响应只更新仍选中的详情。

`-serve` 显式启动本地界面及 daemon；默认 `127.0.0.1:8787`，禁止非回环监听。仅受信任本机单用户使用；CSRF 随机 nonce 是进程内防伪值，不是部署凭据。任何 LAN/反向代理暴露之前必须实现独立用户认证、TLS 和授权，当前版本拒绝配置 LAN 地址。无 CORS；精确 Host、写请求 Origin、JSON Content-Type、CSRF 自定义头共同校验，所有响应 no-store，静态 CSP 禁止内联脚本。无网络监听仍是默认行为。

## 未接入契约

gateway 只读取 `/api/events?after=<cursor>` 的有界事件页；按 `(instance, event ID)` 持久去重，确认 Discord 成功后才保存 cursor。崩溃后重放至少一次；Discord 自身没有端到端幂等保证，因此发送成功但本地未确认可能重复，不能宣称 exactly-once。仅 `discovered` 且当前 job 无阻塞才可以通知就绪；消息由结构化状态确定性渲染，不调用模型。当前 API 只支持本机浏览器会话，不提供网络 gateway 身份认证；远程接入和 asuka-agent 改动另行授权。

命名建议未来只提交建议、来源、置信度和证据；目录/NFO/元数据学习都不直接执行或激活规则。用户确认规则后下一集使用显式规则；这与“自动学习”不同。
