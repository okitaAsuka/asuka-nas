# N1 实施计划

本轮：人工规则（manual provider、自定义 order、稳定 series ID）、不可变版本与启停、本地 CLI、有界 RSS 标题/来源、作用域 alias 和单集相对编号。合集/绝对范围只做解析预览与纯映射，继续拒绝合集执行。

1. schema v3 添加不可变来源上下文、manual series、规则版本/活动版本/事件；原 job 和历史文件不改名。
2. 纯规范化/解析器保留原文和证据；规则只匹配订阅及可选字幕组下的精确 alias。年份/分辨率不作为集数。
3. 单集计划绑定规则代次和来源版本；冲突不能 fallback；启动执行前再次检查并持久化冻结。新来源晚到报告冲突，不移动既有文件。
4. CLI 添加草稿、预览、启用、停用；过期未执行计划必须明确 replan，不默改。CLI 与 daemon 使用同一实例锁，改规则时先停止 daemon。
5. 用虚构已确认季号 fixture 验证用户例一 [02]/[03] 连续自动入库；例二只解析 S4/1–11/67–77，不执行。覆盖规则冲突、标题/文件矛盾、历史冻结、启停/版本失效及日志秘密边界。
6. 独立逐段复核、完整 race/vet/build；提交当前独立分支，替换同一 Library bundle 的受保护版本。无元数据联网、模型、Discord、真实 NAS 或远端权限重试。
