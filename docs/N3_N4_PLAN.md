# N3/N4 实施计划

复核 N1：现有东京复仇者测试包含中英篇章和质量信息，但未覆盖实体编码及完整括号结构；补合成完整标题 fixture，不将样例映射当外部事实。现有规则没有“更具体胜出”，同 subscription 下 group 专属与宽规则若决定不同必须冲突；补直接测试。历史 plan 已有不可变记录及冻结门槛。

1. 规则添加显式集范围和有界绝对映射；绝不按清单顺序分配。相对优先，有绝对证据则交叉验证。特殊篇、多集单文件、缺集/重复/范围不一致整包阻塞。
2. 完整清单分组，字幕只绑定同目录/同 stem 唯一视频；所有文件预检、目标唯一，整包计划冻结 manifest/指纹/逐视频决定。
3. schema v4：目标预约唯一表、逐文件执行表、事件附 plan_version/file_index。plan_ready 原子保存历史和预约；每次 link 前持久 intent，link 后持久 linked。不删除成功硬链，失败时保持 planned。
4. 所有视频逐一确认 Emby discovery；只有全部确认才产生最终 discovered（ready）事件。做种截止仍先行。
5. 故障注入覆盖中段 link 后数据库失败、权限失败、重启改规则、跨任务预约冲突和部分媒体发现。单独审查 SQL/状态机，全套 race/vet/build、提交、替换原 Library v1。无网络元数据/LLM/Discord/真实 NAS/GitHub 重试。
